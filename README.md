## 3) المعاينة محليًا

افتح `index.html` مباشرة في المتصفح. لا يحتاج أي خادم.
لخادم محلي: `python -m http.server 8080` ثم افتح `http://localhost:8080/`.

---

## 4) النشر (استضافة مجانية دائمة)

- **GitHub Pages:** مستودع باسم `dehya-beauty` → ارفع الملفات → `Settings → Pages → Deploy from a branch → main / (root)` → الرابط يكون `https://<user>.github.io/dehya-beauty/` (كما في `sitemap.xml` و`canonical`).
- **Netlify Drop:** افتح `https://app.netlify.com/drop` واسحب المجلد كاملًا. (يلاحظ أنه لتفعيل الرابط يجب إنشاء حساب مجاني.)
- **Cloudflare Pages:** `Workers & Pages → Create → Pages → Upload assets`.

الدومين الحالي في `sitemap.xml` و`canonical` مؤقت: `https://monstorjohan-png.github.io/dehya-beauty/` — يُستبدل عند ربط الدومين النهائي.
